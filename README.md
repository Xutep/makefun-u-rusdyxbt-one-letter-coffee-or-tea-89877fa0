## The entry

`main.py` (Python 3.13, stdlib only, fully deterministic) writes exactly one
letter to `/output/entry.txt`:

```
A
```

**A = coffee.** Why coffee? The judge weighs vividness, humour and truth
first. Coffee is the louder answer: the first jolt of the day, dark, hot and
impatient — the drink people reach for when they need to wake up and mean
it. Tea is calm and polite; coffee is the punchline. One letter, no
explanation, no punctuation — the choice stands on its own.

## Run it

```sh
python3 main.py
cat /output/entry.txt   # A
```
